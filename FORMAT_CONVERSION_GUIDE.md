# Converting temp_0-main Dataset to HuggingFace Format

## Overview

Your `temp_0-main` dataset is in **PyTorch format** with full trajectories, while the standard project uses **HuggingFace format** with pre-processed input/output pairs.

## The Two Formats

### 1. Your temp_0-main Format (PyTorch)

**File**: `temp_0-main/dataset_and_model/re1000_grid=256_1_N=40_dt=4.0_Ttj=200-320(stat).pt`

```python
Shape: [40, 481, 256, 256]
  Axis 0: 40 trajectories
  Axis 1: 481 timesteps  
  Axis 2-3: 256×256 spatial grid

Structure: Raw vorticity values
Dtype: float32
Normalization: None (raw data)
```

**Characteristics**:
- ✅ Full temporal trajectories
- ✅ High resolution (256×256)
- ❌ No train/test split
- ❌ Need to manually extract input/output pairs
- ❌ Not normalized

### 2. Standard HuggingFace Format

**Files**: `data/DiffPDE/ns-nonbounded_hf/` (train), `ns-nonbounded_test_hf/` (test)

```python
Structure per sample:
  {
    'id': int,           # Sample index
    'data': [2, H, W]     # Stacked input+output (H,W can be 128 or 256)
  }

Shape: data = [2, H, W]
  data[0]: Input (normalized)
  data[1]: Output (normalized)

Dtype: float64
Normalization: Applied (stats in metadata.json)
```

**Characteristics**:
- ✅ Ready for training (random access)
- ✅ Pre-normalized
- ✅ Train/test split
- ✅ Resolution: 128×128 or 256×256
- Only 2 timesteps per sample (input + output)

## Conversion Requirements

To convert temp_0-main → HuggingFace format, you need to:

### Step 1: Extract Input/Output Pairs

```python
# From your full trajectory
trajectory = data[traj_id]  # Shape: [481, 256, 256]

# Extract pairs with time gap Δt
dt = 2  # Prediction horizon in timesteps
pairs = []
for t in range(len(trajectory) - dt):
    input_field = trajectory[t]      # At time t
    output_field = trajectory[t + dt] # At time t + dt
    pairs.append([input_field, output_field])
```

**For your dataset**:
- `station.py` uses `dtsave = 0.25`
- Target prediction: `t + 0.5` physical time
- In timesteps: `0.5 / 0.25 = 2` timesteps

### Step 2: Normalize (REQUIRED)

```python
# Compute statistics
mean_input = all_inputs.mean()
std_input = all_inputs.std()
mean_output = all_outputs.mean()
std_output = all_outputs.std()

# Normalize
normalized_input = (input - mean_input) * (0.5 / std_input)
normalized_output = (output - mean_output) * (0.5 / std_output)
```

The `0.5` factor scales data to roughly [-1, 1] range.

**Why normalization?** The training pipeline (`DatasetNormalizer`) expects pre-normalized data in the HF format. The `metadata.json` file stores the mean/std stats for denormalization later.

### Step 3: Stack Channels

```python
sample_data = np.stack((normalized_input, normalized_output), axis=0)
# Shape: [2, 256, 256] for your data (no downsampling!)
```

### Step 4: Create Train/Test Split

```python
# Use some trajectories for train, others for test
# Example: 32 for train, 8 for test
train_trajs = range(32)
test_trajs = range(32, 40)

# Or split randomly
import numpy as np
np.random.shuffle(pairs)
split_idx = int(0.8 * len(pairs))
train_pairs = pairs[:split_idx]
test_pairs = pairs[split_idx:]
```

### Step 6: Save as HuggingFace Dataset

```python
from datasets import Dataset, Features, Array3D, Value

features = Features({
    'id': Value('int32'),
    'data': Array3D(shape=(2, 256, 256), dtype='float64')  # Your resolution
})

def data_generator(pairs):
    for i, pair in enumerate(pairs):
        yield {'id': i, 'data': pair}

dataset = Dataset.from_generator(
    generator=lambda: data_generator(train_pairs),
    features=features
)
dataset.save_to_disk('data/DiffPDE/my_dataset_hf')

# Metadata is automatically saved by HuggingFace!
# dataset_info.json and state.json are auto-generated
# Only metadata.json is custom (see below)
```

**Important JSON files**:
- `metadata.json` - **Custom file** you must create with stats, shape, num_samples
- `dataset_info.json` - Auto-generated by HuggingFace (don't create manually)
- `state.json` - Auto-generated by HuggingFace (don't create manually)

## Complete Conversion Script Template

```python
import torch
import numpy as np
import os
from datasets import Dataset, Features, Array3D, Value

# Load your PyTorch data
data = torch.load('temp_0-main/dataset_and_model/re1000_grid=256_1_N=40_dt=4.0_Ttj=200-320(stat).pt')
data = data.numpy()  # Convert to numpy

# Parameters
PREDICTION_TIMESTEP = 2  # Predict 2 timesteps ahead (0.5 physical time)
RESOLUTION = 256  # Keep your full resolution, no downsampling needed!

# Step 1: Extract pairs
pairs = []
for traj_idx in range(data.shape[0]):  # For each trajectory
    trajectory = data[traj_idx]  # [481, 256, 256]
    for t in range(trajectory.shape[0] - PREDICTION_TIMESTEP):
        input_field = trajectory[t]
        output_field = trajectory[t + PREDICTION_TIMESTEP]
        pairs.append([input_field, output_field])

print(f"Extracted {len(pairs)} pairs")

# Step 2: Normalize (REQUIRED - HF format stores normalized data)
all_inputs = np.array([p[0] for p in pairs])
all_outputs = np.array([p[1] for p in pairs])

mean_input, std_input = all_inputs.mean(), all_inputs.std()
mean_output, std_output = all_outputs.mean(), all_outputs.std()

normalized_pairs = []
for input_field, output_field in pairs:
    norm_input = (input_field - mean_input) * (0.5 / std_input)
    norm_output = (output_field - mean_output) * (0.5 / std_output)
    stacked = np.stack((norm_input, norm_output), axis=0).astype(np.float64)
    normalized_pairs.append(stacked)

# Step 3: Split train/test (by trajectory, not random)
# Split by trajectory (maintain temporal consistency)
train_pairs = []
test_pairs = []
for traj_idx in range(data.shape[0]):  # 40 trajectories
    start_idx = traj_idx * (data.shape[1] - PREDICTION_TIMESTEP)
    end_idx = (traj_idx + 1) * (data.shape[1] - PREDICTION_TIMESTEP)
    traj_pairs = normalized_pairs[start_idx:end_idx]
    
    if traj_idx < 32:  # First 32 for training
        train_pairs.extend(traj_pairs)
    else:  # Last 8 for testing
        test_pairs.extend(traj_pairs)

print(f"Train pairs: {len(train_pairs)}, Test pairs: {len(test_pairs)}")

# Step 4: Create HuggingFace datasets
features = Features({
    'id': Value('int32'),
    'data': Array3D(shape=(2, RESOLUTION, RESOLUTION), dtype='float64')
})

def create_dataset(pairs, split_name):
    def generator():
        for i, pair in enumerate(pairs):
            yield {'id': i, 'data': pair}
    
    dataset = Dataset.from_generator(generator, features=features)
    output_dir = f'data/DiffPDE/ns-temp0main_{split_name}_hf'
    dataset.save_to_disk(output_dir)
    
    # Save custom metadata.json (REQUIRED for DatasetNormalizer)
    import json
    metadata = {
        'name': 'ns-temp0main',  # Dataset name
        'stats': {
            'mean': [float(mean_input), float(mean_output)],
            'std': [float(std_input), float(std_output)],
            'min': [float(all_inputs.min()), float(all_outputs.min())],
            'max': [float(all_inputs.max()), float(all_outputs.max())]
        },
        'shape': [2, RESOLUTION, RESOLUTION],
        'num_samples': len(pairs),
        '__version__': '2.0'
    }
    with open(os.path.join(output_dir, 'metadata.json'), 'w') as f:
        json.dump(metadata, f, indent=2)
    
    print(f"Saved {len(pairs)} samples to {output_dir}")
    print(f"  metadata.json created with stats")

create_dataset(train_pairs, 'train')
create_dataset(test_pairs, 'test')
```

## Summary

**Your temp_0-main format**:
- Full temporal trajectories
- Raw, unnormalized data
- High resolution (256×256)
- All data together

**HuggingFace format**:
- Pre-processed pairs
- Normalized data (using mean/std in metadata.json)
- Resolution can be 256×256 (your data) or 128×128 (if downsampled)
- Train/test split

**Conversion steps**:
1. Extract input/output pairs from trajectories (0.5s gap)
2. **Normalize data** (required - applies during conversion)
3. Split into train/test by trajectory (32 vs 8)
4. Save as HuggingFace dataset with metadata.json

**Notes**:
- **No downsampling needed** - keep 256×256 resolution
- **Normalization REQUIRED** - done during conversion, stats saved to metadata.json
- **metadata.json is critical** - used by DatasetNormalizer for denormalization
